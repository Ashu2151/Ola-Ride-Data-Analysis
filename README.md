# Ola Dashboard Analysis

## Project Overview
This project is a Power BI dashboard created for analyzing Ola ride booking data.

The dashboard provides insights into:
- Total Bookings
- Revenue Analysis
- Ride Cancellation Trends
- Customer Ratings
- Driver Performance
- Ride Distance Analysis
